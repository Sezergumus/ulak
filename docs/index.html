Under the hood · For engineers

Rust core, strict bounds, verifiable by design.

For those curious about how it works beneath the UI: Ulak separates an authoritative Rust core from its Tauri v2 Windows shell and React 19 interface.

Bounded 64 KiB streaming & locked handles

Files stream straight from Windows handles (denying concurrent writes/deletion) using fixed 64 KiB buffers—never buffered into RAM or passed through WebView JSON.

Ed25519 identity & commit-before-reveal pairing

Device IDs are BLAKE3 hashes of persistent Ed25519 keys. Nearby 6-digit pairing binds descriptors and 256-bit nonces via signed commitments before reveal over pinned local CA TLS (rustls + rcgen).

Crash-safe resume & lazy Explorer COM streams

Native downloads persist flushed byte offsets in .part files, validate ETag revisions and HTTP ranges, and verify complete BLAKE3 digests. Explorer drag-out serves lazy range-backed IDataObject/IStream streams with XChaCha20-Poly1305 opaque entry IDs.
